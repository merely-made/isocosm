# Isocosm: VTT

Name reservation for **Isocosm: VTT**, the virtual tabletop of the Isocosm
family (formerly Isometry; renamed 2026-09-22).

A pixel-art isometric virtual tabletop: a peer-to-peer map editor and
turn-based play substrate for D&D, Pathfinder and other systems, over the
Isocosm simulator. The implementation is the `isometry-*` crates of the
umbrella repository, <https://github.com/merely-made/isometry>, which keep
that prefix as a plain technical name.
